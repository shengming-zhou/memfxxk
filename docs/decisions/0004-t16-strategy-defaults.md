# 保留混合检索为默认行为

T16 的阶段评测中，增加写入策略有时能改善少数题型，但结果受语料、题型和模型成本影响。未设置预设时保持原有关键词和向量检索、显式管理与宿主调度。将自动事实写入、时序图构建、笔记加工、后台整理、分层、反思重排与自动提炼作为可配置功能。启用组合预设时，明确的独立配置优先，方便使用同一环境做受控试验。

`full` 使用 Mem0 additive 写事实，让图和事实都能参与召回。首次组合试验中，单个两轮案例触发了 155 次 A-Mem 邻居复查。将该预设的 `amem_enrich_mem0_facts` 默认设为 false，保留对笔记和经验的加工。独立 A-Mem 策略仍可加工自动事实。
