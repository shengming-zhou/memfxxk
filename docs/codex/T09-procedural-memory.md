# T09 · 保存和复用经验

依赖 T03、T05。对应 M3 的程序性记忆，使用架构中的 `lesson` 记录。

## 范围

- 通过 API、同步及异步 SDK 和可选 MCP 管理工具，显式保存带场景、前置条件、步骤和验证结果的经验。
- 原文必须包含可见的失败和后续成功工具结果。宿主用 `payload.outcome` 记录结果，服务保留两个事件 ID。重复保存使用幂等键。
- 复用现有检索、版本管理、索引和原文删除逻辑。自动装载由宿主显式选择 `lesson` 类型，用户也可以主动固定经验。

## 验收

- 用真实 PostgreSQL 复现一次数据导出失败和修复。下一会话能按需召回经验，从原文回查验证结果，再用同一份输入完成导出。
- 验证越权来源、无效结果和删除证据后的行为。覆盖 API、SDK 和 MCP 正常路径。
- 记录原文回放和手工重复任务结果。AMA-Bench 与真实 Agent 的复发率继续作为 M3 验收门槛。
