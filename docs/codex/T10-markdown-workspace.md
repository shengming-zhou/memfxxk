# T10 · Markdown 工作区迁移

依赖 T04、T09。工作区导出包含当前请求精确作用域中的 Markdown 文档与显式选择的活动经验。

- 用目录保存 Markdown 正文，用清单保存文档用途、加载策略、版本来源和经验的执行证据。纯 Markdown 目录也可作为新文档导入。
- 导入在一个事务里进行。相同内容可重试，冲突时保留目标内容。显式更新文档时核对导出的文档 ID 和基础版本。
- 经验在目标作用域生成新的记忆和原文 ID，保留原始 ID 供追溯。历史版本与用户标记继续由原工作区持有。
- 验收覆盖 CLI 往返、隔离、文档冲突、经验回查和原文删除，以及目录边界和可移植路径。
