# 长篇写作的记忆评测

**默认继续用固定分区。** 在这套题里，自适应找到了相关章节，却把武器名 Ironsilk Blade 压成了 Ironsilk，少答对一题。反馈和模型微调都拿到了有效系数，装载结果没有改变。

## 怎么测 {#writing-eval-method}

用原创的盐玻璃港设定和正文，共 8 份文档、8 道问答、5 段真冲突、3 段干净草稿。五个受限组都允许 420 个记忆 token，全原文组作上限参考。检索使用本机 BGE 英文向量，答题用 `gpt-5.4-mini`，规划用 `deepseek-flash`。反馈组先回放 4 轮补读设定的写作过程。Lorebook 组实现了关键词匹配、优先级排序、整条装载三个规则。 [SillyTavern World Info 文档](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)

「完整证据」要求整条标注的设定句进入上下文。冲突检出要求草稿片段和设定引文均可核实，文件引用另计。首轮请求把草稿标为 `CONFLICT`，六组都误报了三段干净草稿。换成中性提问后，只抽查固定和自适应各 3 条。两组均检出 2/2 真冲突，干净草稿均无误报。这六条结果不足以替换上表的全量冲突数据。

自适应有三条题的来源成功召回，后来都在摘要装载时失去部分设定。`q05` 失去武器名字的后半段。`q07` 和 `c05` 失去盟约名称的后半句，仍保留了两方是盟友的关键信息。100% 前缀表示这批相邻请求得到相同记忆文本，属于可共享长度估算。它同时说明这批请求的装载缺少变化。

首轮共有 64 次实际 GPT 请求和 16 次 DeepSeek Flash 规划调用，合计 39,084 token。32 个相同的 GPT 请求读了评测本地缓存。中性提示复核另用 3,112 token。固定和自适应的全程 p50 分别为 950 与 938 ms，p95 为 1,070 与 1,330 ms。规划组的模型答题复用了本地缓存，装载延时仍包含规划调用。
