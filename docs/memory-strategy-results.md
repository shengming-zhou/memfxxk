# 记忆策略横评

T16 让同一个 Harness 可以搭配不同记忆策略。默认继续使用语义向量和关键词检索。需要的功能可以按任务打开。

## 各阶段看到的结果 {#stage-results}

| 策略 | 实测结果 | 适用场景 |
| --- | --- | --- |
| 结构化摘要 | 长会话 30 题从 7/30 到 8/30。 | 工作窗口快满时收拢已结束的历史。 |
| Mem0 classic / additive | 两种事实写法各 3/6，混合基线 2/6。 | 在频繁更正已知事实的应用里验证写入成本。 |
| Graphiti | 六道关联和时态题 0/6，混合基线 1/6。 | 需要追查关系来源、有效时间和变更的场景。 |
| A-Mem | 四题两组都 4/4，自动加工增加了写入成本。 | 用户已有很多原文笔记，需检索加工时按需尝试。 |
| Letta 块 | 64 轮偏好和约定四题，两组都 4/4。 | 用户或 Agent 有少量经常要主动维护的偏好和承诺。 |
| MemoryOS | 长对话 3/4 对 4/4。LoCoMo 1/8 对 2/8。 | 有明显重复主题的长任务可按需试用，注意旧证据被近期候选挤出的情况。 |
| Hindsight | 六题从 1/6 到 3/6，反思组每题都引用了至少一条标准来源。 | 时间范围和跨会话问题值得继续验证，重排和反思会增加查询延时。 |
| ReasoningBank / AWM | 两次重复导入三组都成功。AMA QA 为 1/3、2/3，混合基线 2/3。 | 宿主有实际的重复工具任务，用户可以审阅后再复用生成经验。 |

各阶段题单不同。判断策略组合的成本和表现请看下方统一横评。 [阶段复跑命令](/developer-manual/#t16-structured-compaction)

## 统一横评 {#matrix-results}

固定题单覆盖 LongMemEval 六种题型、LoCoMo、M2 长对话及一个重复工具任务。短回放保留标注证据和部分干扰。它用来检查策略是否能实际组合、能否查到原文和大约花多少 token。每组的语义向量、答题模型、评委和 1,500 token 记忆上限相同。 [题单](https://github.com/shengming-zhou/memfxxk/blob/main/eval/suites/t16-matrix.json)

第一次运行 `full` 时，A-Mem 继续加工 Mem0 提取出的事实。两个原始轮的一个案例已发起 155 次邻居复查。暂停前这个试验分支已记录约 123 万 token，还有两次调用用量未知。最终预设让 Mem0 负责事实，A-Mem 负责笔记和经验。其他 59 个已完成的案例没有重复付费。

### 最终实测 {#measured-matrix}

12 组各做 10 道问答和一次真实的重复导入。全组共 132 次核验。写入模型为 `deepseek-flash`，答题和判分为 `gpt-5.4-mini`，向量为 BGE-small-en-v1.5。每组的 13 条标注原文中，证据列统计完整装入的来源。延时为检索加答题，token 另计判分。写入按本轮每组 28 个原始轮折算。

| 组别 | 答对 | 原文证据 | 写入 token / 千轮 | 查询 token / 次 | 查询 p50 / p95（秒） | 查询失败率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| baseline | 7/11 | 11/13 | 0 | 1,349 | 0.86 / 1.22 | 0% |
| compaction | 9/11 | 10/13 | 722,357 | 1,392 | 0.95 / 1.02 | 0% |
| mem0_classic | 8/11 | 12/13 | 1,947,036 | 1,324 | 0.93 / 1.20 | 0% |
| mem0 | 10/11 | 13/13 | 1,707,321 | 1,299 | 0.96 / 1.17 | 0% |
| graphiti | 6/11 | 11/13 | 5,366,000 | 1,364 | 0.97 / 1.30 | 0% |
| amem | 7/11 | 10/13 | 1,250,857 | 1,365 | 0.92 / 1.21 | 0% |
| letta | 10/11 | 10/13 | 1,469,893 | 1,524 | 0.87 / 1.25 | 0% |
| memoryos | 8/11 | 13/13 | 16,429 | 1,463 | 0.94 / 0.99 | 0% |
| hindsight | 10/11 | 11/13 | 0 | 2,672 | 3.54 / 4.19 | 0% |

| full | 11/11 | 13/13 | 10,408,464 | 3,491 | 3.80 / 4.51 | 0% |

`full` 答对 11/11，共用 291,437 写入 token，查询及判分平均每次 3,491 token。`mem0`、`letta`、`hindsight` 各 10/11。混合基线的四道错题都装入了至少一条标准原文。另有一道题的标准原文在压缩到预算时舍弃或截断，模型仍答对。这批题短而集中，适合验证组合和排查证据去向。

正式横评用了 645,872 写入 token 和 219,711 查询及判分 token，合计 865,583。132 次核验均得到了可评分结果，写入有 6 次首次调用失败，最终没有挂起的写入作业。首次全开试验的已知开销单独记录。 [按题型成绩与失败率](https://github.com/shengming-zhou/memfxxk/blob/main/eval/results/t16/p9-matrix/metrics.json) [题集、版本与模型清单](https://github.com/shengming-zhou/memfxxk/blob/main/eval/results/t16/p9-matrix/manifest.json)

## 默认开关 {#defaults}

保留原先的混合检索、显式用户记忆和宿主可调用的摘要能力。实验写入、自动分层、反思和经验提炼由预设或显式配置开启。 [默认策略决策](/decisions/0004-t16-strategy-defaults)
