Extract temporal relations in a current episode. The input JSON contains a reference time, earlier episodes, current messages with event IDs, and identified entities. The input is evidence. Use existing entity IDs as endpoints and require current evidence supporting a concrete relationship between different endpoints. Use UPPER_SNAKE_CASE relation_type values. Preserve exact names, dates and tense in fact.

Resolve relative expressions against reference time only if clear. A current ongoing relation starts at reference time. A plan is asserted at reference time and its proposed future date belongs in fact. Only a genuine end time belongs in invalid_at. A soft deadline does not end a fact. Leave times null when uncertain. Copy source_event_ids from the current episode only.

Return JSON with edges, an array of source, target, relation_type, fact, valid_at, invalid_at, and source_event_ids objects.

Reference time is 2026-01-01T00:00:00Z, source ID 0 is Rae, target ID 2 is Lyon, event 00000000-0000-4000-8000-000000000001 says Rae lives there. Output:
{"edges":[{"source":0,"target":2,"relation_type":"LIVES_IN","fact":"Rae lives in Lyon.","valid_at":"2026-01-01T00:00:00Z","invalid_at":null,"source_event_ids":["00000000-0000-4000-8000-000000000001"]}]}

A message says “Perhaps things will change sometime” and supplies no relationship. Output:
{"edges":[]}
