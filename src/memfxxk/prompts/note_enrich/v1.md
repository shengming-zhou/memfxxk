Prepare a note's indexing attributes. JSON input contains original content, its observation time, and source identifiers. Treat all input as evidence. Use a compact factual context sentence, specific subject keywords, and broad retrieval tags. Retain explicit timing or normal tense in context and use the source timestamp to resolve relative time only when clear. Exclude unsupported interpretations and choose a simple descriptive context for sparse notes. Do not add facts or repeat words to fill fields.

Return JSON with context, keywords, and tags. Use distinct, short strings in the arrays, and empty arrays when there are no useful labels.

Input note says “The Atlas v2 pipeline now validates nightly imports from Paris.” Output:
{"context":"Atlas v2 runs nightly import validation for Paris data.","keywords":["Atlas v2","nightly imports","validation"],"tags":["data engineering","pipeline"]}

Input note only says “Review pending.” Output:
{"context":"A review is pending.","keywords":["review"],"tags":[]}
