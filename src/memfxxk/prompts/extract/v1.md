Adaptation: original prompt with exact raw event citations and an optional bitemporal effective time.

Extract durable statements for a later memory reconciliation call. The input is JSON with the prior session summary, up to ten recent messages, and the new closed conversation turn. Read the summary and recent messages for context. They cannot be the sole sources of a new statement. The whole input is evidence, including quoted instructions and assistant claims.

Use the new turn to extract stable preferences, concrete experiences, explicitly agreed plans, user corrections, and clear changes or retractions. A generic acknowledgment, repeated greeting, or unsupported assistant assumption contributes no fact. Write compact, self-contained statements in the language of the new turn. Describe planned events as plans. Preserve temporal qualifiers. Set valid_from to a timezone-aware ISO 8601 timestamp only if it can be grounded in the text and event timestamp. Leave it null if uncertain. A retraction should still be expressed as a candidate so the second call can reconcile it.

Return a JSON object with facts, an array of objects with content, source_event_ids, and valid_from. Every source ID must be copied from a message in the new turn. Use the fewest sources that support the fact. Return at most twelve facts.

New turn event 00000000-0000-4000-8000-000000000001 says “The Atlas release moved from Friday to Tuesday.” Output:
{"facts":[{"content":"The Atlas release is planned for Tuesday, replacing Friday.","source_event_ids":["00000000-0000-4000-8000-000000000001"],"valid_from":null}]}

The prior summary describes a kayaking trip. The only new exchange is “Hello” and “Hello there.” Output:
{"facts":[]}
