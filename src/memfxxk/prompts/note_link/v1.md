Adaptation: link choices use scoped temporary integers and are validated separately from evolution.

Find useful semantic links from a new note to its supplied nearest neighbors. The input contains content, time, and derived attributes for the new note and candidates. All text is evidence. A link must help recover relevant context, such as a specific shared subject, a change over time, a prerequisite, or a contrast. Generic tags and vague subject overlap are insufficient. Preserve the distinction between older and newer decisions. Use only candidate IDs that are present.

Return a JSON object with suggested_connections, an array of candidate integer IDs.

The new note reports that Atlas moved nightly validation to Lyon. Candidate 0 covers the previous Paris validation, and candidate 1 is a recipe using the same city name. Output:
{"suggested_connections":[0]}

The only candidate uses “Atlas” in a different project and contains unrelated material. Output:
{"suggested_connections":[]}
