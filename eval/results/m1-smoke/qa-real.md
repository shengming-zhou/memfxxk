# First live LongMemEval QA comparison

The runs requested `gpt-5.4-mini` for both generation and the built-in judge over an OpenAI-compatible gateway. Each replay used the top eight ranked turns, an evidence budget of 1,500 tokens, and a 384-token answer limit. The judge applied LongMemEval's question-type rubrics. This run records the gateway model alias.

## Frozen 50-question suite

The memories come from the earlier evidence run with shared deterministic hash vectors. The responses and scores were generated by the live model.

| Group | Correct | Correct abstentions | Replay and response p95 |
| --- | ---: | ---: | ---: |
| No history | 6 / 50 | 4 / 4 | 1.73 s |
| Recent turns | 4 / 50 | 4 / 4 | 0.90 s |
| memfxxk hybrid | 15 / 50 | 4 / 4 | 1.02 s |
| Mem0 raw | 11 / 50 | 4 / 4 | 1.09 s |

The p95 column includes context assembly and generation for questions that made a network call. Retrieval timing comes from the [evidence run](evidence-hash/latency.json). Four questions were correct only with memfxxk hybrid, with zero correct only with Mem0 raw in this run. [Per-type scores](qa-real-frozen50/metrics.md)

The 35 incorrect memfxxk hybrid answers included 27 questions without a gold turn in the top eight, five with a gold turn ranked but absent from the injected IDs, two with a gold turn ID injected, and one without an eligible gold turn label. A source ID can refer to a truncated excerpt or one of multiple supporting turns.
